# Changelog — Olympus

## [Unreleased]

### Added
- **Shift test**, a protein-level test with a controlled false discovery rate:
  - paired refit per temperature with Deimos' limma (`limma_ebayes.py` from
    `shift_test.deimos_dir` / `DEIMOS_DIR`), reading the Deimos `matrices/` folder;
  - windows of adjacent temperatures, with the adjacent-temperature correlation in
    the variance, Simes per protein and BH over proteins;
  - localisation check against the profile median, which rejects constant offsets.
- **Permutations within lysates**: FDR estimates for the shift test and for the
  legacy rule (sheet `FDR_estimates`, column `legacy_rule_fdr_estimate`).
- Outputs: sheet `Shift_test`, `shift_test.csv`, `shift_windows.csv`,
  `shift_test_plots.pdf`; new Summary columns `shift_hits` and `shift_min_q`.
- Intensity simulator (`olympus.synthetic.simulate_intensity_series`,
  `write_intensity_runs`) and validation script `docs/validation/simulate_shift.py`.
- Dependency: scipy. CI clones Deimos for the engine.


### Changed
- **Renamed FC.TPP (Python) → Olympus**, after Olympus Mons. Package `olympus`
  (pip distribution `olympus-tpp`), command `olympus analyze`, results workbook
  `Olympus_Results.xlsx`, default output folder `olympus_output`, test variables
  `OLYMPUS_R_PROJECT` / `OLYMPUS_DEIMOS_RESULTS`. The R package keeps its name.
- Icon and mark (`olympus_icon.svg`, `olympus_mark.svg`, PNG/ICO in `assets/`),
  generated by `assets/generate_icon.py`.

### Checked
- Compatibility with Deimos `main` `e160463` (17/11/2026): 12 TPP temperatures
  rerun, same workbook layout read, same results (2,041 proteins, same 3 hits and
  flags); `-m realdata` and `-m deimos` suites pass; every module compiles on
  Python 3.11.
- Documented the Deimos `primary_statistic: dpc` default: one pr_matrix for every
  temperature or for none, so that the X runs use the same statistic.

## [0.1.0] — 2026-09-27

First Python release. Port of the R package FC.TPP (0.0.0.9000, 2025), with the
DEP part delegated to Deimos.

### Added
- `olympus analyze`: TPP layer on the X Deimos result workbooks, one per temperature,
  whatever X. Flexible discovery: one folder per temperature, renamed files in one
  folder, `--temperature-regex`, or a manifest. A long-table mode also reads the R
  `TPP_data` sheet.
- Presence filter checked against X, and accepting fractions of the series
  (`--min-temperatures 0.5`).
- `strict` call rule (adjacent temperatures, same sign). The `r_legacy` rule
  reproduces the R calls exactly.
- Hit flags: `shift_class` (thermal / abundance-like / undetermined / mixed-sign),
  `imputed_in_run`, the calling run (`run_start`–`run_end`), direction.
- Checks that the X Deimos runs were processed the same way (`Methods` sheet). A
  contrast that comes out reversed at one temperature is flipped back automatically.
- Temperatures in °C (optional) for ordering and axes. The series is no longer
  fixed to T1..T12.
- Single Excel workbook with Methods, Summary, Hits, TPP_data, Stats_proteins,
  Calls, FC/logP matrices and input provenance (SHA-256).
- Volcano grid per contrast, FC/-log10 p profiles, lighter interactive 3D HTML,
  and a GIF without webshot2/ImageMagick.
- Tests: synthetic and CLI tests, parity with the R outputs (`-m realdata`), real
  Deimos outputs (`-m deimos`). GitHub Actions CI.

### Changed (vs R)
- The DEP part of the R package (`process_tsv`, `format_tsv`, `sumXP`,
  `process_and_export`) is replaced by the Deimos runs made upstream: QRILC
  instead of MinProb, and BH `p.adj` instead of the DEP/fdrtool q-value.
- Volcano thresholds follow the call thresholds by default (R used 0.3 against 0.6
  for the calls).
- Figure labels use gene names; the accession is used when there is no gene name.

### Fixed (vs R)
- The R Excel export overwrote itself from one function to the next (only
  `TPP_data` and `Stats_proteins` survived).
- The default design folder `tpp_data` did not match `TPP_data` on case-sensitive
  file systems.
- The misleading "proteins were imputed" message (it counted the proteins removed
  by the filter) is gone; filtering is documented in the Deimos Methods sheet.
